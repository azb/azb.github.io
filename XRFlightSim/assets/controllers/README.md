# Meta Quest Touch controller models

Converted from the Meta/Oculus Integration meshes bundled with Strategeality:

- `Assets/Oculus/VR/Meshes/OculusTouchForQuest2/OculusTouchForQuest2_Left.fbx`
- `Assets/Oculus/VR/Meshes/OculusTouchForQuest2/OculusTouchForQuest2_Right.fbx`
- Albedo from `Assets/Oculus/VR/Textures/OculusTouchForQuest2/OculusTouchForQuest2_AlbedoRoughness.tga`

ASCII FBX → OBJ → GLB (Blender 3.6). No Quest 3 / Touch Plus meshes were present in Strategeality; Quest 2 Touch is the closest web-friendly pair.
